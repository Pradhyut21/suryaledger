# Reporting a security concern

This is a single-user local prototype. Keep it bound to loopback and use synthetic data. Do not assume that a tunnel adds authentication or tenant isolation.

Do not publish credentials or personal data in an issue. When a repository is hosted, its owner should enable private vulnerability reporting before accepting sensitive reports. No monitored security email or response guarantee is claimed here.

Known boundaries: local reviewer names are not authenticated; browser drafts are editable; source quotes are not signed recordings; live tool snapshots are ephemeral. The report tool requires a separate Bearer token and an issued per-call routing ID, but those controls are not a complete production access model.
