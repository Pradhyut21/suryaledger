# Validate before expanding

## Before submission

1. Run the replay and rehearse the 90-second pitch. Show a missing test, a source quote, a conflicting statement and explicit review.
2. Connect Bolna with a synthetic test agent and verify microphone denial, network loss, insufficient credits, wrong-site speech, corrections, tool failure and a late final callback. Record actual run IDs and failures. Account-backed connection/callback tests are recorded in LIVE-VALIDATION.md, but complete spoken-report reliability and the listed failure scenarios remain unverified.
3. Interview three installer operators and two technicians. Collect ten consented, de-identified reports; compare a form, a plain summary and this workflow. Report raw counts and failures.
4. Publish the source and pitch only after checking for secrets and personal data. Share the pitch through the accepted Drive/Docs or Luma host; verify anonymous link access.

## A useful next version

- Correlate submitted tool text with provider transcript events and recording identifiers. Label unmatched claims rather than presenting them as independently verified speech.
- Add authenticated organizations, job assignment, reviewer identities, durable revisioned storage, retention and deletion controls.
- Evaluate critical entities separately: site/equipment ID, negation, action, units and measurement. Broaden language coverage using a consented gold set; abstain on uncertain extraction.
- Compare a model-backed extractor against the rule baseline with the same source-span and contradiction requirements. Check facts against original text instead of trusting schema-valid output.
- Integrate one installer's existing work-order tool through an export or API. Avoid rebuilding scheduling, billing, inspection analytics and customer CRM.

Do not use sensor readings, photos or customer signatures as proof until their capture, identity, timestamps and tamper assumptions are designed and evaluated. A documentation tool should not prescribe electrical procedures.

## Stop or pivot when

If technicians prefer their existing structured form, the clarification cost exceeds the benefit, or operators already have the same workflow, revise the niche instead of adding features. The first milestone is one operator willing to evaluate real reports, not an unsupported market-size number.
